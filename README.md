# weather-dashboard
I'm so excited to share my third project in python which evolves around getting the current weather by just entering the city name which makes easy to access weather.
The program usually starts by asking the user to enter the name of a city or location,after recieving the input,the program connects to a weather API such as OpenWeatherMap using the internet.
The program sends the request containing the city name and an API key.
The weather service then returns the data such as temperature,humidity,windspeed,and weather conditions in a format called JSON.
Python reads the JSON data and stores it in variables or dictionaries so the information can be accessed easily.
After processing the data,the program may convert temperature from Kelvin to Celcius using C=K-273.15
Overall,a Python weather program works by taking user input,requesting data from an online weather service,processing the returned information,and displaying the results in user-friendly way.
